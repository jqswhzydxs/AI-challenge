### input_schema.md 输入数据格式说明

#### 字段定义

| 字段名    | 类型     | 单位 | 必填 | 说明                         |
| --------- | -------- | ---- | ---- | ---------------------------- |
| timestamp | datetime | —    | 是   | 时间，格式：dd/MM/yyyy HH:mm |
| elec      | float    | kWh  | 是   | 该时刻用电量                 |
| steam     | float    | 吨   | 否   | 可填0或留空                  |

#### 数据粒度
- **输入粒度：15分钟**
- 最少需要30天数据（15分钟粒度不少于2880个点；1分钟粒度不少于43200个点）

#### 处理方式
- 程序内部通过 PCHIP 插值将15分钟重采样为1分钟
- 缺失值自动线性插值填充

#### output_schema.md 输出数据格式说明

#### 日级计划字段（daily_plan）

| 字段                  | 类型   | 单位   | 说明           |
| --------------------- | ------ | ------ | -------------- |
| timestamp             | string | —      | 计划生成时间   |
| plan_horizon          | int    | 小时   | 固定24         |
| data_granularity      | string | —      | 1 minute       |
| EC_baseline           | float  | kWh/吨 | 基准能耗 14.00 |
| EC_optimized          | float  | kWh/吨 | 优化能耗 13.28 |
| EC_reduction          | float  | %      | 降低率 5.15    |
| total_production      | float  | 吨     | 日总产量       |
| total_energy          | float  | kWh    | 日总能耗       |
| optimal_temperature   | int    | ℃      | 1140           |
| optimal_speed         | float  | m/s    | 11.0           |
| schedule[].hour       | int    | —      | 0-23           |
| schedule[].demand     | float  | 吨     | 该小时需求     |
| schedule[].production | float  | 吨     | 该小时排产     |

#### 实时调控字段（realtime_control）

| 字段                        | 类型   | 单位 | 说明              |
| --------------------------- | ------ | ---- | ----------------- |
| timestamp                   | string | —    | 当前时刻 HH:MM:SS |
| control.boiler_load         | float  | MW   | 锅炉负荷指令      |
| control.turbine_output      | float  | MW   | 汽机出力指令      |
| control.grid_purchase       | float  | kWh  | 外购电力          |
| control.power_factor_target | float  | —    | 0.95              |
| forecast.elec_next_5min     | float  | kWh  | 5分钟用电预测     |
| forecast.steam_next_5min    | float  | 吨   | 5分钟蒸汽预测     |
| performance.ER              | float  | %    | 方案可执行率      |

### requirements.txt

MATLAB版本: R2022b 或更高
所需工具箱: Optimization Toolbox
依赖: 无第三方依赖
运行耗时: 约 10-15 秒
输入数据: 15分钟粒度，至少30天
输出数据: 1分钟粒度的日级计划 + 实时调控指令

### 输入粒度说明

输入数据：15分钟粒度（原始工厂采集频率）
程序内部：通过 PCHIP 保形插值重采样为1分钟
输出数据：1分钟粒度（满足比赛要求）
