# 用户手册

> 系统名称：生产-能源交互式优化平台  
> 版本：v1.0  
> 整理日期：2026-08-01

## 1. 使用对象

本系统面向生产调度、能源管理、系统管理员和项目展示人员。

| 用户 | 主要关注内容 |
| --- | --- |
| 系统管理员 | 用户、角色、系统配置、操作日志 |
| 生产调度员 | 生产订单、排产方案、排产历史、方案对比 |
| 能源管理员 | 能源监控、能源方案、设备状态、MPC 调控 |
| 项目展示人员 | 首页看板、核心指标、协同评估、报表 |

## 2. 登录系统

打开系统地址后进入登录页，输入账号和密码。

默认联调账号：

| 账号 | 角色 | 说明 |
| --- | --- | --- |
| `admin` | 系统管理员 | 可用于完整演示 |
| `dispatcher` | 调度员 | 用于生产排产模块 |
| `energy` | 能源管理员 | 用于能源运行模块 |

登录成功后进入首页看板。

## 3. 首页看板

首页用于快速查看系统整体运行情况。

建议重点查看：

- 当前生产计划状态。
- 能源负荷情况。
- 方案执行率。
- 告警信息。
- 能耗、成本、碳排等摘要指标。

如果首页指标为空，通常说明数据库初始化数据未导入完整，可检查是否已执行 `seed_demo_data.sql`。

## 4. 生产排产

### 4.1 查看生产订单

进入“生产排产”模块后，可查看订单列表，包括订单编号、产品、规格、计划数量、交期、优先级和状态。

当前订单数据主要用于联调展示，后续可替换为真实业务订单。

### 4.2 上传原始数据生成排产方案

系统支持上传钢铁能源 CSV 原始数据，由后端默认调用 Python 算法程序自动生成排产方案和 MPC 调控结果；MATLAB 版本作为旧版兜底保留。

操作流程：

1. 进入生产排产模块。
2. 选择上传原始数据。
3. 上传 CSV 文件，至少包含时间戳和用电量字段。
4. 提交后系统返回任务 ID，并进入“生成中”状态。
5. 等待算法任务完成。
6. 查看排产方案详情、MPC 调控结果和协同评估结果。

生成成功后，系统会生成：

- 排产方案主记录。
- 24 小时排产明细。
- 评价指标记录。
- 能源运行方案。
- 协同评估结果。
- MPC 实时调控记录。

当前后端接口为：

```text
POST /api/production/schedules/generate-from-raw-data
GET  /api/tasks/{taskId}
```

系统仍保留“导入算法排产 JSON”能力，例如导入 `daily_plan_v3.2.json`，用于联调或算法服务不可用时的兜底。

### 4.3 查看排产方案概览

排产方案概览建议重点查看：

| 指标 | 当前主案例口径 |
| --- | --- |
| 优化前 EC | `14.00 kWh/t` |
| 优化后 EC | `13.2785 kWh/t` |
| EC 降低率 | `5.15%` |
| 总排产量 | 来源于算法排产结果 |
| 总预测能耗 | 来源于算法排产结果 |
| 最优温度 | `1140℃` |
| 最优速度 | `11 m/s` |

注意：“优化前 EC”应理解为算法报告中的基准 EC，不是当前小时电耗。

### 4.4 查看排产明细

排产明细通常按 24 小时展示：

- 小时序号。
- 开始时间和结束时间。
- 小时需求。
- 小时排产量。
- 预测电耗。
- 产线或设备信息。
- 设备负荷率。

其中，需求和排产量来自算法排产结果；设备负荷率当前为后端联调补齐字段，主要用于页面展示。

### 4.5 查看排产历史

进入“排产历史”页面，可查看历史排产方案。

当前数据库已补充联调模拟历史，避免页面为空。主展示案例仍建议使用 `2026-07-17` 算法导入方案。

## 5. 能源运行

### 5.1 实时能源监控

实时能源监控用于查看能源时序数据和实时负荷情况。

可查看：

- 用电量。
- 蒸汽消耗。
- 碳排放。
- 能源成本估算。
- 功率因数。

当前系统支持真实算法数据和联调演示数据共同展示。联调演示数据来源标识为 `demo_20260717_hourly`。

### 5.2 能源方案生成

能源运行方案用于估算生产计划对应的能源消耗、成本、蒸汽和碳排。

生成逻辑：

1. 如果指定日期有能源时序数据，系统按小时聚合生成能源方案。
2. 如果没有对应日期能源数据，系统基于排产方案明细派生能源方案。
3. 系统结合峰谷电价和蒸汽单价计算能源成本。

当前峰谷时段：

| 类型 | 时间 |
| --- | --- |
| 谷段 | `00:00-08:00,22:00-24:00` |
| 峰段 | `08:00-22:00` |
| 平段 | 算法报告未设单独平段，系统保留兼容字段 |

### 5.3 能源设备状态

能源设备状态展示锅炉、汽轮机、外购电接口等设备运行情况。

重点关注：

- 当前输出。
- 最大输出。
- 负荷率。
- 设备状态。
- 告警等级。

当前算法报告约束：

| 设备 | 运行范围 |
| --- | --- |
| 锅炉 | `20-80 MW` |
| 汽轮机 | `5-30 MW` |

### 5.4 能源历史

能源历史页面用于查看历史能耗趋势。如果页面为空，通常是对应日期没有能源时序数据。

当前 seed 已补充 `2026-07-17` 的 24 小时能源历史样例，联调环境重新执行 `seed_demo_data.sql` 后即可查看。

## 6. MPC 实时调控

MPC 实时调控模块用于查看算法组输出的实时调控指令。

### 6.1 查看最新指令

进入“MPC 实时调控”页面，可查看最新一条调控记录：

- 锅炉负荷。
- 汽机出力。
- 外购电力。
- 功率因数目标。
- 未来 5 分钟用电预测。
- 未来 5 分钟蒸汽预测。

### 6.2 查看历史指令

MPC 历史页面可按日期或分页查看历史调控指令。

当前导入数据：

| 文件 | 日期 | 说明 |
| --- | --- | --- |
| `seed_mpc_control.sql` | `2026-07-17` | MPC final 结果 |
| `seed_mpc_hourly.sql` | `2026-07-18` | MPC hourly 结果 |

### 6.3 指令范围说明

系统会校验调控指令范围：

| 指令 | 合法范围 |
| --- | --- |
| 锅炉负荷 | `20-80 MW` |
| 汽机出力 | `5-30 MW` |
| 功率因数目标 | `0.95` |

如果导入数据越界，系统会提示错误。

## 7. 协同评估

协同评估用于判断生产排产方案和能源运行方案是否匹配。

它回答的问题是：

```text
排产方案回答“生产怎么排”
能源方案回答“能源怎么跟上”
协同评估回答“两者匹配得好不好”
```

### 7.1 生成协同评估

操作流程：

1. 选择一个排产方案。
2. 选择对应能源方案。
3. 点击生成协同评估。
4. 查看评估结果和约束冲突。

如果通过上传原始数据触发算法生成，前端可根据任务 ID 等待系统自动完成排产方案、能源方案、MPC 调控结果和协同评估。若使用兜底的算法 JSON 导入入口，也会自动生成能源方案和协同评估。

### 7.2 查看核心指标

当前主案例指标：

| 页面显示 | 字段建议 | 数值 |
| --- | --- | --- |
| 仿真精度 | `simulationAccuracy` | `96.45%` |
| MAPE | `mape` | `3.55%` |
| 轧钢能耗 EC | `ec` 或 `ecReduction` | `5.15%` |
| 可执行率 ER | `er` 或 `executeRate` | `100%` |

注意：`mape` 是误差，不是仿真精度。仿真精度等于 `100 - mape`。

### 7.3 查看约束冲突

约束冲突用于提示能源运行方案是否违反设备能力或运行约束。

当前主要校验：

- 锅炉负荷是否在 `20-80 MW` 范围内。
- 能源输出是否存在越界风险。

如果冲突数为 0，说明当前方案在已建模约束下可执行。

## 8. 报表中心

报表模块用于查看优化效果和能源分析结果。

可查看：

- 优化效果。
- 能源分析。
- 能源趋势。
- 碳减排趋势。
- CSV 导出。

当前部分报表统计数据为联调演示数据，用于展示系统链路。后续可由明细数据自动聚合生成。

## 9. 数据分析

数据分析模块提供能源变量相关性矩阵。

当前相关性矩阵分析 6 个变量：

- 用电量。
- 滞后无功电量。
- 超前无功电量。
- 碳排放。
- 滞后功率因数。
- 超前功率因数。

该矩阵用于展示历史能源变量之间的联动关系，不是优化方案结果。

## 10. 常见问题

### 10.1 为什么页面没有历史数据？

可能原因：

- 没有执行 `seed_demo_data.sql`。
- 对应日期没有导入能源或排产数据。
- 前端查询日期和演示数据日期不一致。

建议优先查询 `2026-07-17`。

### 10.2 能源方案是不是算法组给的？

排产方案和 MPC 调控结果优先由“上传原始 CSV -> 后端调用算法”流程生成；算法组结果文件导入作为联调兜底入口。能源运行方案当前由后端基于排产结果、能源时序、峰谷电价和估算系数派生生成，主要用于能源运行测算和协同评估。

### 10.3 协同评估是不是协同优化模型？

当前系统实现的是协同评估、约束校验和效果分析，尚未接入独立协同优化求解模型。后续如算法组提供模型接口，可替换当前规则测算逻辑。

### 10.4 仿真精度和 MAPE 是什么关系？

MAPE 是误差，当前为 `3.55%`。仿真精度为 `100 - MAPE`，当前为 `96.45%`。

### 10.5 设备负荷率来自哪里？

当前排产明细中的设备负荷率主要是后端联调补齐字段，用于页面展示。后续如果算法组提供设备级负荷曲线，可以替换为算法输出。

## 11. 推荐演示路线

完整演示可按以下顺序：

1. 登录系统。
2. 查看首页看板。
3. 进入生产排产，上传原始 CSV 数据并生成排产方案；如需快速演示，也可查看 `2026-07-17` 兜底排产方案。
4. 查看排产明细和排产历史。
5. 进入能源运行，查看能源历史、能源方案、设备状态。
6. 进入 MPC 实时调控，查看最新指令和历史指令。
7. 进入协同评估，展示仿真精度、EC、ER 和约束冲突。
8. 进入报表中心，展示趋势和导出功能。

建议演示时统一使用 `2026-07-17` 作为主案例日期。
